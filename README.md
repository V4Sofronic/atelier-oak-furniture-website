# Atelier Oak — Artisan Furniture & Home

A luxury furniture and home interiors website featuring a refined aesthetic, artisan craftsmanship, and curated furniture and decor collections.

## Overview

Atelier Oak is a furniture and home interiors website showcasing furniture, lighting, rugs, decorative objects, craftsmanship, and curated interior styling.

## Live Link 
https://atelier-oak-furniture-website.pages.dev/

## Features

- Elegant furniture and interiors presentation
- Furniture collection showcase
- Lighting, rugs, and decor sections
- Seasonal lookbook
- Artisan craftsmanship section
- Responsive layout
- Embedded visual assets

## Technologies

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Local Setup

No installation or build process is required.

Open `index.html` in a web browser to view the website.
